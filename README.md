# Regresion lineal simple

### El objetivo de esta actividad es fue efectuar un análisis de regresión que permita construir un modelo predictivo a una base de datos real para generar pronósticos adecuados.

### Se busca contestar las preguntas:
### - ¿Obtuvo resultados satisfactorios en esta ocasión?
### - ¿Cuál sería su pronóstico del PIB (GDP) para México en el 2022?
